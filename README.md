# D&D Reference — HTML/CSS prototype

Справочник для мастеров.

## Структура

- `html/index.html` — главная
- `html/classes.html` — список классов
    - `html/classes/class-fighter.html` — пример страницы класса
- `html/species.html` — список видов
    - `html/species/species-elf.html` — пример страницы вида
- `html/equipment.html` — список снаряжения
    - `html/equipment/equipment-longsword.html` — пример страницы предмета
- `html/monsters.html` — список монстров
    - `html/Monsters/monster-goblin.html` — пример статблока монстра
- `html/spells.html` — список заклинаний
    - `html/Spells/spell-fireball.html` — пример страницы заклинания
- `html/glossary.html` — глоссарий
- `html/news.html` — новости
- `css/style.css` — общие стили
- `assets/images/` — место для будущих изображений
- `assets/icons/` — место для будущих иконок
