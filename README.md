# D&D Reference — HTML/CSS prototype

Справочник для мастеров.

Это сайт по DnD(настольная ролевая игра в сеттинге фентези) содержащий разную информацию для мастеров(судей/режиссёров/рассказчиков). 
Тип сайта: веб-сервис / информационный справочник
Стиль: Классический стиль с элементами минимализма и фэнтезийной стилистики
Структура: В основном структура такая: из index.html можно на страницы со списками других страниц (например виды-список видов персонажей, из него можно попасть на страницу конкретного вида), также есть глоссарий - список с правилами, где через ссылки в тексте можно находить нужное правило. Для навигации на каждой странице есть боковая колонка со всеми основными страницами.
PS Все монстры, классы и заклинания ведут на одну страницу, я не успел заполнить информацию для других страниц, но это не важно, так как визуально это были бы те-же страницы, просто с другой информацией.

## Структура

- `html/index.html` — главная
- `css/`
    - `css/style.css` — общие стили
- `html/`
    - `html/classes.html` — список классов
    - `Classes/`
        - `html/classes/fighter.html` — пример страницы класса
    - `html/species.html` — список видов
    - `Species/`
        - `html/Species/dwarf.html` — страница вида
        - `html/Species/elf.html` — страница вида
        - `html/Species/halfling.html` — страница вида
        - `html/Species/human.html` — страница вида
    - `html/equipment.html` — список снаряжения
    - `Equipment`
        - `html/equipment/battleaxe.html` — страница предмета
        - `html/equipment/dagger.html` — страница предмета
        - `html/equipment/heavy-crossbow.html` — страница предмета
        - `html/equipment/longsword.html` — страница предмета
        - `html/equipment/shortbow.html` — страница предмета
        - `html/equipment/shortsword.html` — страница предмета
    - `html/monsters.html` — список монстров
    - `Monster/`
        - `html/Monsters/goblin.html` — пример статблока монстра
    - `html/spells.html` — список заклинаний
    - `Spells/`
        - `html/Spells/fireball.html` — пример страницы заклинания
    - `html/glossary.html` — глоссарий
    - `html/news.html` — новости
- `images/` — место для изображений
